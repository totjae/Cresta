# 거래 세션 및 감시 운영 명세

## 1. 목적

장 시작 전 점검부터 NXT 애프터마켓 종료까지 Cresta의 감시, AI 분석, 신규매수와 장 마감 청산 시간을 정의한다.

## 2. 적용 범위

- KRX 국내주식 정규시장과 동시호가
- NXT 프리마켓, 메인마켓과 애프터마켓
- 장 시작 전 시스템 점검
- 집중·일반 AI 분석 주기
- 신규매수 가능 시간과 장 마감 처리

## 3. 상세 명세

### 3.1 기본 일정

| ID | 요구사항 | 기본값 | 사용자 설정 |
| --- | --- | --- | --- |
| SES-001 | 장 시작 전 점검 시작 | 07:30 | 아니요 |
| SES-002 | 시장 감시 시작 | 08:00 | 예 |
| SES-003 | 시장 감시 종료 | 20:00 | 예, 거래 가능 세션 범위 내 |
| SES-004 | 집중감시 시작·종료 | 08:00~11:00 | 예 |
| SES-005 | 집중 AI 분석 주기 | 5분 | 5분 또는 10분 |
| SES-006 | 일반감시 시작·종료 | 11:00~20:00 | 예 |
| SES-007 | 일반 AI 분석 주기 | 10분 | 10분 또는 30분 |
| SES-008 | 신규매수 가능 종료 | 10:00 | 예 |

감시 주기는 Scout/Core 분석 주기다. 실시간 시세 수신, 데이터 최신성 검사와 Guard 손절 검사는 AI 분석 주기와 무관하게 계속 수행한다.

사용자 조절 범위는 감시 시작 08:00~15:30, 감시 종료 09:00~20:00이며 시작은 종료보다 빨라야 한다. 집중·일반 구간은 이 감시 범위 안에서 겹치지 않고 연속되어야 한다. 첫 버전은 종목 유동성별로 장 마감 청산 시각을 자동 변경하지 않고 종목별 명시적 재정의만 허용한다.

### 3.2 장 시작 전 점검

07:30 점검은 다음 순서로 수행한다.

1. 거래일과 휴장 여부 확인
2. 키움 접근토큰과 서버 환경 확인
3. 계좌 잔고, 보유 수량과 전일 상태 조회
4. 내부 주문·포지션과 키움 계좌 재동기화
5. 감시 종목의 거래 가능 여부와 거래소 지원 여부 확인
6. 전략, 손절가, 한도와 실행 모드 검증
7. 실시간 연결 및 구독 준비
8. 비상정지와 전일 미해결 오류 확인

점검이 완료되지 않으면 신규매수를 차단하되 가능한 범위에서 기존 포지션 감시는 계속한다.

### 3.3 시장별 시간

설계 기준 시간은 다음과 같다.

```text
NXT 프리마켓       08:00~08:50
KRX 개장 동시호가  08:30~09:00
KRX 정규장         09:00~15:30
NXT 메인마켓       09:00:30~15:20
KRX 종가 동시호가  15:20~15:30
NXT 애프터 호가접수·시가 단일가 15:30~15:40
NXT 애프터 연속매매              15:40~20:00
```

거래시간은 외부 제도이므로 하드코딩하지 않고 거래 캘린더 설정으로 관리하며 운영 전에 공식 자료와 키움 지원 시간을 다시 확인한다.

거래 캘린더는 거래일, 시장별 세션, 임시 휴장·단축장과 근거·확인시각을 가진 불변 버전으로 저장한다. 자동으로 확인되지 않은 날짜는 평일이라는 이유만으로 거래일로 간주하지 않는다. 07:30 점검 때 당일 캘린더가 없거나 공식 일정과 충돌하면 신규매수를 차단하고 운영자가 근거와 TOTP 재인증을 포함한 새 캘린더 버전을 등록해야 한다.

| ID | 요구사항 |
| --- | --- |
| SES-010 | 거래 캘린더는 시장·거래일별 세션, timezone, 출처, 확인시각과 버전을 포함한다. |
| SES-011 | 캘린더가 없거나 모순되면 신규 주문을 fail-closed 처리한다. |
| SES-012 | 임시 캘린더 수정은 기존 버전을 덮어쓰지 않고 변경 사유·근거·재인증과 함께 새 버전으로 감사한다. |
| SES-013 | NXT 애프터마켓은 15:30~15:40 호가접수·시가 단일가 구간과 15:40~20:00 연속매매 구간을 구분한다. 주문 유형과 체결 가능성 표시는 현재 구간을 따라야 한다. |

| ID | 요구사항 |
| --- | --- |
| SES-020 | 신규매수 기본 가능 시간은 08:00~10:00으로 한다. |
| SES-021 | 사용자는 허용된 거래 세션 범위 안에서 시작·종료 시각을 조절할 수 있다. |
| SES-022 | NXT 불가 종목은 설정이 08:00이어도 실제 거래 가능 시점까지 주문을 생성하지 않는다. |

### 3.5 동시호가

동시호가는 일정 시간 주문을 모아 하나의 가격으로 일괄 체결하는 방식이다. 주문 제출 시점에는 최종 체결가격을 확정할 수 없으므로 연속매매와 별도 설정으로 관리한다.

```yaml
auction_policy:
  opening_auction_buy: DISABLED
  opening_auction_sell: MANUAL_APPROVAL
  closing_auction_buy: DISABLED
  closing_auction_sell: AUTOMATIC
```

| ID | 요구사항 |
| --- | --- |
| SES-030 | 개장·종가 동시호가 매수와 매도를 독립적으로 설정한다. |
| SES-031 | 개장 동시호가 신규매수 기본값은 금지한다. |
| SES-032 | 종가 동시호가 신규매수 기본값은 금지한다. |
| SES-033 | 익일 보유 금지 시 종가 동시호가 매도 참여를 허용한다. |
| SES-034 | 승인 화면에는 동시호가 주문이며 체결가격이 미확정임을 표시한다. |

### 3.6 장 마감 청산

강제청산 시작 시각은 무조건 즉시 시장가 주문을 보내는 시각이 아니라, 익일 보유 금지 포지션의 청산 절차를 시작하는 시각이다.

```yaml
end_of_day_exit:
  mode: AUTOMATIC
  regular_exit_start_time: "15:10"
  closing_auction_start_time: "15:20"
  extended_exit_start_time: "15:40"
  final_exit_deadline: "19:50"
```

| ID | 요구사항 |
| --- | --- |
| SES-040 | `FORBID_OVERNIGHT`이면 기본 15:10부터 청산을 시작한다. |
| SES-041 | 미체결 잔량은 종가 동시호가와 이후 거래 가능한 세션에서 계속 처리한다. |
| SES-042 | 최종 거래 종료 후 남은 수량은 숨기지 않고 예외 포지션으로 기록하고 경보한다. |
| SES-043 | `ALLOW_OVERNIGHT`이면 설정에 따라 미체결 매도를 취소하고 포지션을 이월할 수 있다. |
| SES-044 | 종목별 NXT 가능 여부와 주문 유효시간을 확인하지 않고 KRX 주문을 NXT 주문으로 간주하지 않는다. |
| SES-045 | 사용자는 종목의 실행시장을 KRX 또는 NXT로 고정하지 않는다. 주문시장은 [거래시장 자동 선택 명세](VENUE_SELECTION_SPEC.md)에 따라 평가시점마다 계산한다. |
| SES-046 | 08:00~08:50과 15:40~20:00에는 NXT 적격 종목만 NXT 후보가 되며, 부적격 종목은 아직 열리지 않았거나 종료된 KRX로 우회하지 않고 대기한다. |

### 3.7 정기 AI scheduler 슬롯

| ID | 요구사항 |
| --- | --- |
| SES-050 | scheduler 기준 timezone은 `Asia/Seoul`이며 첫 구현은 평일 08:00 이상 20:00 미만에만 동작한다. 거래 캘린더가 구현되기 전까지 SHADOW 이외 단계 확대는 금지한다. |

## 4. 오류·예외 또는 경계 조건

- 키움 모의투자는 공식 문서상 국내주식 KRX만 지원하므로 NXT 시간대 주문은 첫 버전 모의투자에서 실제 검증할 수 없다.
- NXT 미지원 종목, 거래정지, VI와 세션 휴장 상태는 일정보다 우선한다.
- 20:00까지 청산되지 않았다고 매도가 성공한 것으로 기록하지 않는다.
- 서버 시간이 거래소 시간과 허용 오차를 넘으면 신규매수를 차단한다.
- 장 운영시간 변경, 임시 휴장과 수능일 같은 개장시간 변경을 거래 캘린더에서 지원해야 한다.

## 5. 검증·인수 조건

- 07:30 점검 실패 시 신규매수가 차단된다.
- 집중·일반 분석 주기가 사용자 설정대로 전환된다.
- AI 주기를 길게 설정해도 실시간 손절 검사는 중단되지 않는다.
- NXT 불가 종목은 프리마켓 주문이 생성되지 않는다.
- 동시호가 허용·금지 설정이 주문 생성에 반영된다.
- 익일 보유 정책에 따라 장 마감 미체결 처리와 포지션 상태가 달라진다.
